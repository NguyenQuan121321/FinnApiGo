## 3. Clean-Code Criteria

- `gofmt -l .` prints nothing; `go vet ./...` is clean; `golangci-lint run`
  is clean; no new gosec findings. Never silence findings with `#nosec` or
  `//nolint` in new code.
- `internal/swagger/types.go` contains **only** documentation types: pure
  structs with `json` + `example` tags, no logic, no `interface{}`, no
  `gin.H`, no generics. Field names and JSON tags must mirror the payloads
  actually produced by `internal/response.Respond` (`code`, `message`,
  `data` envelope) and the handlers.
- Example values are short, obviously fake, and lowercase
  (`user@example.com`, `<access-token>`). Never real tokens, never real user
  data, no long high-entropy strings (gosec noise).
- swag annotation blocks sit **immediately** above the handler function —
  no blank line between the comment block and `func`.
- Comments in code state constraints the code cannot show; no narration
  comments ("this line does X").
- Follow the existing repo style: file layout, comment tone (design-rule
  references like `§2`, `A3`), naming, and error handling idioms.

### W4 — Mount the gated route in `internal/routes/routes.go`

  Serving docs with `no-store` is acceptable and keeps the middleware model

## 10. Known Pitfalls (from pre-implementation review)

- swag parses annotation blocks only when they sit directly above the
  function — a blank line silently drops the endpoint from the spec.
- `--parseDependency --parseInternal` is required for `handlers.*Request`
  DTO schemas to resolve; without them `@Param` references render empty.
- Two `@Success 200` lines on one operation are invalid: for `Login`, model
  the MFA-pending outcome the way the handler actually responds (read it),
  and describe the dual outcome in `@Description`.
- Envelope `message` values in examples must match reality (`"ok"`,
  `"account created"`, ...), not aspirational text.
- `/swagger` (no trailing slash) is not a UI route — always link
  `/swagger/index.html`.
- The worktree has no `.env` (untracked files do not propagate across
  worktrees); copy from the main checkout for the smoke test only.
